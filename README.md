# Простой Telegram-бот для учета трат

Бот работает без ИИ и внешних сервисов. Данные хранятся локально в SQLite.

## Формат записи

Одна трата:

```text
еда 500
```

Несколько трат — строго через запятую:

```text
еда 500, супермаркеты 2300, транспорт 250
```

Первое слово считается категорией, последнее число — суммой, а всё между ними — комментарием:

```text
подарки родителям на годовщину 3500
```

Без даты трата записывается на текущий учётный день. Он заканчивается в 04:00 по часовому поясу пользователя: например, покупка в 02:30 первого октября относится к 30 сентября. Явно указанная дата остаётся приоритетной. Дату можно поставить в начале сообщения — тогда она применяется ко всем тратам:

```text
23.09 еда 500, транспорт 250
23.09.2026 еда 500, транспорт 250
```

Для разных дат в одном сообщении дата ставится после каждой траты:

```text
еда 500 22.09, транспорт 250 23.09
```

Регистр категории не имеет значения: `транспорт`, `Транспорт` и `ТРАНСПОРТ` сохраняются как одна категория «Транспорт».

Флаг `ЕЖЕМЕСЯЧНО` распределяет сумму по всем дням выбранного месяца:

```text
Зал 2500 ЕЖЕМЕСЯЧНО
23.09 Зал 2500 ЕЖЕМЕСЯЧНО
```

Сумма делится с точностью до копейки, а `/undo` удаляет всё распределение целиком.

## Запуск

1. Создай бота через `@BotFather` в Telegram и получи токен.
2. Запусти:

```bash
export TELEGRAM_BOT_TOKEN="токен_от_BotFather"
export ALLOWED_TELEGRAM_USER_IDS="563057258,656675199"
export BOT_TIMEZONE="Asia/Tomsk"
python3 bot.py
```

Процесс должен оставаться запущенным, чтобы бот отвечал и присылал сообщения по расписанию.

## Команды

- `/start` — начало работы и подсказка;
- `/budget 70000` — месячный бюджет;
- `/salary 100000` — месячная зарплата; `/salary 0` убирает её;
- `/income подработка 5000` — другой доход; `/income 23.09 подработка 5000` — доход за дату;
- `/incomes` — список доходов; `/income_delete ID` — удалить ошибочную запись;
- `/refund 123 800` — возврат по номеру покупки из `/history` (исходная трата остаётся); `/refund Еда 800` — возврат без привязки;
- `/goal 20000` — месячная цель накоплений; `/goal 0` — убрать;
- `/free` — сколько свободно до конца месяца после цели и планов;
- `/plan 15.10 стоматолог 15000` — планируемая трата; `/plans` и `/plan_delete ID` — список и удаление;
- `/report` — с 1 октября 2026 года отчёт за текущий календарный месяц (с 1-го по последнее число), с кнопками переключения месяцев; до октября старый вид отчёта сохраняется;
- `/report 10.2026` — отчёт за конкретный календарный месяц;
- `/report 01.09 15.09` — отчёт за произвольный период;
- `/compare` — сравнение текущей и прошлой недели;
- `/compare_months` — сравнение текущего месяца с прошлым;
- `/week` — итог завершившейся недели;
- `/history` — последние покупки; покупку можно открыть и посмотреть комментарий;
- `/limit Еда 20000` — месячный лимит категории;
- `/limits` — показать лимиты;
- `/limit_delete Еда` — удалить лимит;
- `/recurring add 5 Интернет домашний 900` — ежемесячный автоплатёж 5-го числа;
- `/recurring` — список и удаление регулярных платежей;
- `/favorite add Еда бизнес-ланч 600` — добавить быструю трату;
- `/favorites` — кнопки избранных трат;
- `/search такси` — поиск по комментариям;
- `/export` — выгрузка всех трат в CSV;
- `/import` — загрузка CSV из экспорта: отправь CSV-документ с подписью `/import` (один файл не импортируется повторно);
- `/settings` — показать настройки; `/settings cutoff 4`, `/settings reminders 20 22 0`, `/settings morning 9`, `/settings profit 10`, `/settings timezone Asia/Tomsk` — изменить их;
- `/undo` — удалить последнюю запись;
- `/zero` — отметить день без трат;
- `/help` — показать формат ввода.

Если бюджет задан, каждое утро в 09:00 бот показывает доступный бюджет. Если не задан, он напоминает об этом только по понедельникам в 09:00. Зарплата хранится отдельно для каждого пользователя; `/report` показывает зарплату и разницу между ней и тратами текущего месяца на сегодня. При заданной зарплате в 10:00 бот присылает итог за завершившийся учётный день: зарплата за месяц, делённая на число дней того месяца, минус траты дня. В 20:00 бот напоминает записать расходы. Если пользователь не ответил и не нажал «Сегодня без трат», бот повторяет напоминание в 22:00 и 00:00.

По понедельникам в 11:00 бот присылает итог прошлой недели. Зарплата учитывается с даты изменения, поэтому старые дневные итоги не пересчитываются по новой ставке. Другие доходы добавляются к прибыли в день получения. Возврат сохраняется отдельной отрицательной записью и уменьшает траты. Если за текущую неделю категория превысила более чем вдвое обычный недельный расход за предыдущие четыре недели, бот отмечает это после записи траты. Настройки времени индивидуальны для каждого пользователя.

Начиная с октября `/report` привязан к календарным границам месяца, а не ко всей истории трат. Распределённые флагом `ЕЖЕМЕСЯЧНО` суммы учитываются за весь выбранный месяц, включая ещё не наступившие дни текущего месяца. Старые данные и отчёты за произвольный период остаются доступны.

Кнопка «Уже всё записал» останавливает дальнейшие напоминания на этот день и удаляет сообщение с кнопками, не изменяя список трат.

В `/history` у каждой покупки есть кнопки редактирования и удаления. После нажатия
«Редактировать» нужно отправить исправленную покупку целиком; `/cancel` отменяет действие.

Регулярный платёж создаёт одну обычную трату в заданный день каждого месяца. Флаг
`ЕЖЕМЕСЯЧНО` работает по-прежнему и распределяет одну сумму по всем дням месяца.

```bash
python3 -m unittest -v
```

## Деплой в Railway

Production разворачивается в Railway из ветки `main` этого репозитория через `Dockerfile`.
Для сохранения базы между перезапусками сервису нужен volume, подключенный к `/data`.

Переменные окружения:

- `TELEGRAM_BOT_TOKEN` — секретный токен от BotFather;
- `ALLOWED_TELEGRAM_USER_IDS` — Telegram ID пользователей через запятую; данные каждого хранятся отдельно;
- `BOT_TIMEZONE=Asia/Tomsk`;
- `MORNING_HOUR=9`;
- `DATABASE_PATH=/data/expenses.db`.
